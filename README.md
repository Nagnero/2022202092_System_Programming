# System Programming FTP Project

3학년 시스템 프로그래밍 수업에서 단계적으로 구현한 FTP 실습/과제 저장소.  
C 언어와 POSIX 시스템 콜을 사용해 명령 파싱, 파일 시스템 처리, TCP 소켓 통신, 다중 프로세스 서버, 접근 제어, 사용자 인증까지 확장해 가는 흐름으로 구성.

이 README는 폴더 구조와 실제 코드 동작 기준으로 정리. 일부 소스 파일의 헤더 주석에는 이전 과제명이 남아 있음.

## 개발 환경

- Language: C
- OS: Ubuntu 20.04.6 LTS 64bit 기준
- Build: `gcc`, `make`
- Runtime: Linux/POSIX 환경 권장

## 프로젝트 개요

이 저장소는 하나의 완성본만 있는 형태가 아니라, 과제 단계별 결과물이 각각 폴더로 남아 있는 구조.

- 초기 과제: `getopt()` 사용, `ls` 유사 프로그램 작성
- 중간 과제: 사용자 명령을 FTP 명령으로 변환하고 서버 쪽 파일 시스템 명령 처리
- 네트워크 과제: TCP 기반 클라이언트/서버 통신
- 고급 과제: `fork()` 기반 동시 접속 처리, 시그널 처리
- 확장 과제: IP 접근 제어, 계정 인증, 로그 기록

| `FTP1_2_B_2022202092` | `ls`와 유사한 디렉터리 출력 프로그램 |
| `FTP1_3_B_2022202092` | Linux 스타일 사용자 명령을 FTP 명령으로 변환하고 서버 로직으로 처리 |

| `FTP2_2_B_2022202092` | `fork()`와 시그널 처리 기반의 다중 프로세스 서버 실습 |
| `FTP2_3_B_2022202092` | 명령 처리 기능을 포함한 멀티프로세스 FTP 서버로 확장 |

## 구현 포인트

- 사용자 명령을 FTP 스타일 명령으로 변환하는 클라이언트 파서 구현
- `NLST`, `LIST`, `PWD`, `CWD`, `CDUP`, `MKD`, `DELE`, `RMD`, `RNFR`, `RNTO`, `QUIT` 처리
- `stat`, `opendir`, `readdir`, `mkdir`, `unlink`, `rmdir`, `rename` 등 파일 시스템 API 활용
- 클라이언트 프로세스 관리를 위한 연결 리스트 사용
- 인증 실패 횟수 제한

## 한계와 참고 사항

- 표준 RFC FTP 서버를 완전히 구현한 프로젝트는 아님.
- 폴더별로 구현 범위가 다르며, 일부 단계는 특정 기능 실습에 초점.
- 코드 전반에 하드코딩된 출력 메시지와 과제 제출용 주석이 포함.
- 일부 파일 헤더 주석의 과제 번호/제목은 실제 폴더 단계와 다를 수 있음.
